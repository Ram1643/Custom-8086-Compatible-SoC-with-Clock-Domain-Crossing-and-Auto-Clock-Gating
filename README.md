# Custom-8086-Compatible-SoC-with-Clock-Domain-Crossing-and-Auto-Clock-Gating
RTL implementation of a 16-bit 8086-compatible SoC featuring a pipelined CPU, L1 caches, and a 4x6 Wishbone matrix. It includes a distributed Clock Domain Crossing (CDC) network with asynchronous FIFOs for multi-frequency IPs, and cycle-by-cycle Integrated Clock Gating (ICG) for dynamic power management.
